# 公開書籍ビューアのクラウド編集
2026-10-25

本文・見出しの編集、項目削除、目次表示と階層の変更、画像の差し替え・白消去・切り抜き、原本へ戻す・直前操作の取り消しを追加。
原本bundleは変更せず、編集差分を本人専用Firestore領域へAES-256-GCMで暗号化して保存。暗号鍵はランダム生成し、同じ本人だけが読めるbookEditKeys/masterへ保存。平文をlocalStorageや公開ファイルへ保存しない。端末間の反映は書籍を開いた時と「クラウドから再読込」で実行。
項目の版番号をトランザクションで検査し、別端末の先行変更を上書きしない。保存失敗時は編集欄を保持。原本が更新されて元HTMLハッシュが変わった項目は編集を自動適用せず通知する。
画像を含む差分は圧縮・暗号化後に分割保存。公開規則は本人のUID・本人確認済み認証に限定。未ログインでの鍵取得は403を確認済み。
初回ライブラリ表示を遅らせないため、Firestore SDKと編集データは本文ビューアを開いた後に読み込む。従来の遅延書籍ロードと全書籍データを保持し、coreは約5.61MB。
検証：DOM・暗号化の7テスト成功、Astroビルド成功、Firestore規則コンパイル・反映成功。書籍ファイルと遅延読み込みmanifestの内容不変を暗号化更新時に確認。
ソース：books-cloud/viewer、public/admin/books-study/edit-cloud.js、edit-crypto.js。public/books-studyにも同じ保存ブリッジを配置。
