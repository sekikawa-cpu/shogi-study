# 管理者ログインとアプリ選択

ブログのヘッダー、スマートフォンのメニュー、フッターにある「管理者ログイン」から `/admin/` を開きます。

1. 登録済みの管理者Googleアカウントでログインします。ポップアップが開けない場合は「同じタブでログイン」を選びます。
2. 本人確認後に「アプリを選択」が表示されます。
3. 「DS検定 学習アプリ」または「書籍アプリ」を選びます。両アプリは同じFirebaseプロジェクト・既定のFirebaseアプリを使用し、ログイン状態を引き継ぎます。
4. 各アプリのヘッダーにある「アプリ選択へ戻る」で管理者メニューへ戻ります。

選択先は `/admin/ds-study/` と `/admin/books-study/` です。従来の `/ds-study/` と `/books-study/` にも戻るリンクを設置しています。画面が古い場合は Ctrl+F5 で再読み込みしてください。

未ログイン、管理者以外、メール未確認の場合には選択メニューを表示しません。メニューの認証判定は既存の `public/ds-study/config.js` を参照し、個別アプリの本人確認も維持しています。DSの教材・進捗のアクセス制御はFirestoreルールで行います。

変更した認証処理のテストは `node --test ds-cloud/admin-menu.test.mjs`、ブログのビルドは `npm run build` です。GitHubのmainへのマージ後、既存のCloudflare Pagesワークフローが公開します。公開失敗を成功扱いしないよう、デプロイ工程の `continue-on-error` は外しています。
